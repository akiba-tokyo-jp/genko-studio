- `qt/LGPL-3.0.txt`・`qt/GPL-3.0.txt`: FSF の原文（Ubuntu 24.04 の `/usr/share/common-licenses/LGPL-3`・`GPL-3` と同じバイト）。
- `icu/LICENSE`: ICU 73.2 の `icu4c/LICENSE`（https://raw.githubusercontent.com/unicode-org/icu/release-73-2/icu4c/LICENSE、sha256 f3005e195ff74d8812cc1f182a1c446fab678d70a10e3dada497585befee5416）。Qt 6.11.2 の公式バイナリ（Linux）に付く ICU の版。
- `xcb-util/*.copyright`: Ubuntu 24.04 の各パッケージ（libxcb-cursor0 0.1.4-1build1・libxcb-icccm4 0.4.1-1.1build3・libxcb-image0 0.4.0-2build1・libxcb-keysyms1 0.4.0-1build4・libxcb-render-util0 0.3.9-1build4・libxcb-util1 0.4.0-1build3）の `/usr/share/doc/<パッケージ>/copyright`。配布物に入れるライブラリ本体は MIT（GPL-2+ とあるのは Debian のパッケージ作成用ファイル）。
- `qt-3rdparty/NOTICES.txt`: Qt 6.11.2 のライブラリとプラグインが中に含む第三者のソフトウェア 77 件の名前・版・ライセンス・著作権表示・ライセンス文。Qt 6.11.2 のソース（https://download.qt.io/archive/qt/6.11/6.11.2/submodules/ の qtbase・qtsvg・qtwayland・qtimageformats）の各 `qt_attribution.json` と、そこが指すライセンスのファイル（無ければ各モジュールの `LICENSES/`）から作った。Qt を作る・試すときだけに使うもの、ほかの OS（Android・macOS・WebAssembly）だけのもの、使っていないモジュール（Qt SQL の SQLite）は除いた（sha256 0d63c4618de8467d4151e698530f4bcea551e9fd77cb730ac8bc5983d62932fa）。
- `nlohmann-json/copyright`: nlohmann/json（MIT。ヘッダーだけでプログラムに組み込まれる）。Ubuntu 24.04 の nlohmann-json3-dev 3.11.3-1 の `/usr/share/doc/nlohmann-json3-dev/copyright`。
- `windows/*.copyright`: Windows の genko.exe に静的に組み込む zlib・libpng・libjpeg-turbo・libtiff・HarfBuzz・libwebp・Little CMS・OpenEXR・Imath・libavif・libaom（PC4 F-a）のライセンス文。Ubuntu 24.04 の各パッケージ（zlib1g 1.3・libpng16-16t64 1.6.43・libjpeg-turbo8 2.1.5・libtiff6 4.5.1・libharfbuzz0b 8.3.0・libwebp7 1.3.2・liblcms2-2 2.14・libopenexr-3-1-30 3.1.5・libimath-3-1-29t64 3.1.9・libavif16 1.0.4・libaom3 3.8.2）の `/usr/share/doc/<パッケージ>/copyright`（同じ作者・同じライセンス。版は vcpkg のものと違うことがある）。Linux ではこれらはコンピューターのものを使うので入れない。
