# PSD の文字の受け渡し（対応表）

C++ 版 Genko の PSD 書き出しには、台詞の文字の扱いが 2 つあります（SPEC.md PSD-01）。原稿には何も保存しません。

| 書き出し方 | 台詞の書き出され方 |
|---|---|
| **見た目優先で画像化**（既定） | 従来どおり（Python 版と同じ PSD）。台詞ごとに、フキダシと文字を 1 枚にした画像レイヤー「台詞 …」 |
| **文字を編集可能なレイヤーとして保持** | 台詞ごとにグループ「台詞 …」を作り、その中に画像レイヤー「フキダシ」、文字レイヤー「本文 #<台詞の ID>」、ルビごとの文字レイヤー「ルビ「読み」 #<台詞の ID>-r<番号>」 |

- 画面: 書き出し… → 形式「PSD（レイヤー付き）」→「文字」。
- コマンド: `genko export <原稿> <フォルダ> --format psd --psd-text editable`（表せない装飾のある台詞を画像にするときは `--rasterize-unsupported` を足す）。何も指定しなければ `--psd-text image`（見た目優先で画像化）。

## 文字レイヤーとして書くもの

| Genko の台詞 | PSD での表し方 |
|---|---|
| 縦書き・横書きの本文 | 縦組み・横組みの文字レイヤー（ポイントテキスト）。文字列は Genko が組んだとおり（話し言葉の末尾の「。」を省いたものはそのまま） |
| 改行 | 段落の区切り。Genko が組んだ列・行の折り返し（文節での折り返し・禁則を含む）どおりに改行する |
| 部分書式（フォント・サイズ・太字・斜体・色） | 文字のスタイルの区切り（ラン）。書体は PostScript 名で指定する（アンチック体は仮名と漢字で別の書体のランになる）。太字・極太は太字（フェイク）、斜体（italic）は斜体（フェイク） |
| 縦中横（「AI」「12」など） | 縦中横 |
| 縦書きの欧文（横倒し／立てる） | 文字の向き（横倒しは標準、立てる設定は直立） |
| 字間（tracking） | トラッキング（1/1000 em） |
| 行間・列の間（leading） | 行送り（行・列の中心どうしの距離） |
| 段落揃え（縦: 上・中央・下・均等、横: 左・中央・右・均等） | 段落の揃え。均等揃えは段落テキスト（エリア内文字） |
| 位置・回転（rotate_deg）・拡縮（長体・平体 scale_x）・傾け（skew_deg） | 文字レイヤーの変形（行列） |
| ワープテキスト（`native_warp`: 円弧・旗・波形など 15 の形、カーブ、水平方向・垂直方向のゆがみ、水平方向／垂直方向） | 文字レイヤーのワープ（同じ形と量）。受取アプリが文字を描き直すときは受取アプリの計算で曲げる |
| 効果文字の単色の塗り | 文字の色 |
| 効果文字の単色の縁取り（白フチ・outline） | レイヤー効果「境界線」（外側・単色）。太さは Genko が描く縁と同じ（Genko の縁は最大 30 画素のため、それより太い指定も 30 画素） |
| ルビ（読み） | 本文とは別の文字レイヤー。同じグループに入れ、名前の `#<台詞の ID>-r<番号>` で本文と対応させる（番号は台詞のルビの順。列・行をまたいで分かれた読みは `.1`・`.2` …） |
| フキダシ | 画像レイヤー「フキダシ」（文字と別） |
| ノンブル・絵・トーン・コマ枠など | 従来どおりの画像レイヤー |

文字レイヤーの画素は Genko が描いた文字（縁取りはレイヤー効果で描かれるので含まない）です。PSD 全体の合成画像は、見た目優先の PSD と同じです。

## 初版で文字レイヤーにできないもの

編集可能モードでは、次の装飾のある台詞を文字レイヤーにできません。PNG・PDF などの書き出しや Genko の画面では、これまでどおり使えます。

| 項目（キー） | 内容 | 影響 |
|---|---|---|
| グラデーションの文字塗り（`gradient`） | 文字をグラデーションで塗る | PSD の文字の色は単色だけのため、文字にできない |
| 画像の文字塗り（`picture_fill`） | 文字を画像で塗る | PSD の文字の色は単色だけのため、文字にできない |
| パスに沿った文字（`text_path`） | 任意の線に沿わせた文字 | パス上文字は初版では書かない |
| 弓なりの曲げ（`arc`） | 文字の並びを弓なりに曲げる（非線形のワープ） | 非線形の変形は文字レイヤーの行列に表せない |
| 四隅を引くゆがみ（`warp`） | 四隅を動かすゆがみ（非線形のワープ） | 非線形の変形は文字レイヤーの行列に表せない |
| ルビのあるワープテキスト（`warp_ruby`） | ルビを振った台詞のワープテキスト | ルビは本文と別の文字レイヤーのため、本文と一緒に曲げられない |
| 傍点（`emphasis`） | 文字の横・上の点 | PSD の文字に傍点がないため、文字にできない |
| 組み方の変わる旧形式のルビ（`ruby_runs`） | 本文の語ごとに持つ読み（Python 版の原稿の形式） | 位置で持つルビにして書くと、読みが本文より長いときなどに画面と違う組み方になるため、その台詞は文字にできない（ルビを振り直すと文字にできる） |
| 回したテキストレイヤーのフキダシ・ルビ・縁取り（`type_turned`） | 行列で回したテキストレイヤーで、フキダシ・ルビ・縁取りのあるもの（テキストレイヤーだけ） | フキダシ・ルビ・縁取りは本文と別のレイヤーのため、回したテキストレイヤーと一緒に回せず、文字にできない |

- 特殊な多重縁（縁取りを何重にも重ねるもの）も初版では対応しません。Genko の文字の縁取りは単色 1 本だけなので、いまは該当する台詞がありません。
- **厳密（既定）**: 該当する台詞が 1 つでもあると、何も書き出さずに止め、ページ・台詞・装飾を一覧で示します。
- **見た目優先**（画面で「その台詞だけ画像にする」、コマンドで `--rasterize-unsupported`）を選んだときだけ、該当する台詞を見た目優先の PSD と同じ画像レイヤー「台詞 …」にします（その台詞の文字は受取アプリで直せません）。ほかの台詞は文字レイヤーのままです。黙って画像にすることはありません（書き出し前に一覧を示し、書き出した後も画像にした台詞を知らせます）。

## テキストレイヤー（文字の層、PC5）

Photoshop の文字レイヤーにあたる Genko のテキストレイヤーは、**文字を編集可能なレイヤーとして保持** を選んだときに PSD の文字レイヤーとして書きます（画素は Genko が描いた文字、レイヤーの不透明度・描画モード・マスク・レイヤースタイルはそのレイヤーに）。**見た目優先で画像化**（既定）では、台詞と同じく画像レイヤーにします。書き出しの一覧・報告では、テキストレイヤーの項目は `layer` にレイヤーの ID が入ります（`line` は台詞だけ）。

| テキストレイヤー | PSD での表し方 |
|---|---|
| ポイントテキスト・段落テキスト（横組み・縦組み） | ポイントテキスト・段落テキスト（エリア内文字）。本文は打ったとおり（改行は段落の区切り）、文字・段落の属性は解決した値 |
| 文字の属性（書体・サイズ・色・トラッキング・行送り・ベースラインシフト・水平比率・垂直比率・疑似太字・疑似斜体・下線・取り消し線・大文字（スモールキャップス・すべて大文字）・カーニング（メトリクス・なし）・標準合字・任意の合字・OpenType の 8 つ（前後関係に依存する字形・スワッシュ字形・オールドスタイル・デザインのバリエーション・タイトル用字形・飾り文字・序数表記・分数字）） | 文字のスタイルの区切り（ラン）の同じ名前の項目。オプティカルカーニングはメトリクスとして書く |
| 段落の属性（揃え 7 種・インデント 3 つ・段落前後のアキ・自動行送り・ハイフネーション） | 段落の区切りの同じ名前の項目 |
| 文字スタイル・段落スタイル | 原稿のすべてのスタイルを名前付きのスタイルとして書き、各ランと段落が使うスタイルを指す（属性はランにも解決した値で書く） |
| アンチエイリアス（なし・シャープ・鮮明・強く・滑らかに・Windows・Windows LCD） | 文字レイヤーのアンチエイリアス |
| 行列（回転・拡縮・ゆがみ）・ワープテキスト | 文字レイヤーの変形・ワープ |
| フキダシに入れたテキストレイヤー（形の無いもの） | 台詞と同じく Genko が組んだとおりの文字レイヤー。フキダシ・ルビ・縁取りがあれば、それらとまとめたグループ（グループにレイヤーの設定。テキストレイヤー自身のレイヤースタイルはグループに付かない） |

- 書かないもの: 可変フォントの軸・言語・上の 8 つ以外の OpenType 機能（`ss01` など）・禁則・約物の詰め・文字の向き（右から左）・Composer の切り替えは PSD に書かない（受取アプリでは既定のまま）。言語の対応表は未確認のため書かない。
- 上の表の「初版で文字レイヤーにできないもの」（グラデーションなど）のあるテキストレイヤーは、厳密な編集可能モードでは止め、それ以外では画像レイヤーにして知らせる。

**PSD を開くとき**: PSD の文字レイヤーはテキストレイヤーとして読みます（本文・ラン・段落・書体・行列・縦横・ワープ・アンチエイリアス、名前付きのスタイルは原稿の文字スタイル・段落スタイルに。名前は改行などを除き、同じ名前があれば番号を付ける）。書体は PostScript 名で Genko に入っている書体を探し、無ければ名前を持ったまま既定の書体で描いて知らせます（書体の置き換えで選び直せます）。Genko の文字で表せないもの（10 万字を超える本文、潰れた行列、ページから 1 m より遠い位置など）は、その層を画像で読んで理由を知らせます。読んだ文字レイヤーの元の設定（TySh）は、文字・位置・スタイル・解像度・ページの画素・色のモードが読んだときのままなら、編集可能の PSD に書き出すときにそのまま書き戻します（変えたら Genko が書き直します）。見つからない書体・画像で開いた文字レイヤーは、開くときのお知らせに出ます。PSD を開き直すまで、すでに保存した原稿は変わりません。

## 注意

- **ルビは本文とは別のレイヤーです。受取アプリで本文を直しても、ルビは自動では追従しません。** 本文を直したら、ルビのレイヤーも合わせて直してください。
- **フォントは PSD にも配布物にも埋め込みません。** PSD には書体の PostScript 名だけを書きます。名前に使うのは英字・数字と「. _ + -」だけで、ほかの文字は除きます（何も残らないときは `Font`。Genko に入っている書体: ZenKakuGothicNew-Bold・ZenOldMincho-SemiBold・ZenMaruGothic-Bold・Yomogi-Regular・DelaGothicOne-Regular・ReggaeOne-Regular）。受取側に同じ書体がなければ、受取アプリが別の書体に置き換えます。台詞が指定した書体が見つからない（既定の書体で描いた）場合と、台詞の書体にない字を別の書体で描いた場合は、書き出す前に警告します。
- 文字の大きさ・字間・行送りは PSD の中では画素で持ちます（Photoshop はファイルの解像度で pt に換算して表示します）。
- 受取アプリで文字を直すと、その受取アプリの組版で描き直されます。約物の詰め・禁則・ルビの位置が Genko と少し違うことがあります。
- 受取アプリでの再編集（Photoshop・CLIP STUDIO PAINT で開いて文字を直して保存すること）は未確認です（ACCEPTANCE.md §6 で利用者判断により実施不要）。代わりに、PSD の文字の構造を psd-tools と Genko の読み込みで検査し、Krita で開けることを確かめます（FIXTURES.md F4）。
