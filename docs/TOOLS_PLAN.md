# 人が仕上げる道具を揃える計画（M10〜M16）

前提（2026-09-25 の決定）:

- 他のお絵描きソフトは使わない。ネームから仕上げ・入稿まで、Genko だけで人が手を入れられるようにする。
- エージェントとの分担と人の承認は今のまま必須。エージェントでは足りないところを人が直す。
- 道具はすべて GUI から使え、同じ操作が op（`apply_ops`）にもある（エージェント・CLI・HTTP からも使える）。
- 比べる相手は CLIP STUDIO PAINT EX のマンガ制作の機能。全部を真似るのではなく、商業原稿を仕上げるのに要るものを揃える。

## 土台の決定

| 項目 | 決定 | 理由 |
|---|---|---|
| 線 | ベクターが正本。表示・書き出しの解像度でその都度描く | 600 dpi の入稿でもギザギザにならない。消しゴムで線を切れる。軽い |
| ラスター（塗り・トーン・読み込んだ絵） | 描いた範囲だけを原稿の解像度で持つ | B4 600 dpi のページ全体を持つとレイヤーごとに数百 MB になる |
| レイヤー | ベクター・ラスター・トーン・フォルダ・配置した絵。描く先は選んだレイヤー | 人が自分で描き分ける |
| 画面の速さ | 線を引いてから 0.1 秒程度で出る。横のパネルは後で更新 | 描く道具として最低限 |

## マイルストーン

### M10 描画の土台と致命的な不具合

**実施状況（2026-09-25）:** 実装した（`tests/test_m10.py`）。線を 1 本引いてから画面に出るまで約 0.03 秒（以前は 0.8〜1.3 秒）。

- 線をベクターで持ち、描き直す（焼き込みをやめる）。レイヤーの順番どおりに合成する。
- 消しゴム: 線を切る（ベクター消し）。ラスターは透明にする。
- 描く先 = 選んだレイヤー。レイヤーの追加（ベクター / ラスター）・名前の変更・削除・並べ替え・不透明度・ロック。
- 速さ: 線を引いたら画面だけ描き直し、横のパネルは見えているものだけ後で更新する。
- 台詞: 選んだコマの中に縦書きで入る。一覧から編集・削除、フキダシの種類・縦横の切り替え（最小限。本番は M11）。
- コマの枠線の太さの不具合。画面に仕上がり線・裁ち落とし・基本枠を出す。
- 画像の読み込み（選んだコマに / ページに）。

### M11 写植（テキスト・フキダシ）

**実施状況（2026-09-25）:** 実装した（`tests/test_m11.py`）。書体は Zen Kaku Gothic New・Zen Old Mincho・Zen Maru Gothic・Yomogi・Reggae One を同梱（SIL OFL）。アンチックは明朝のかなとゴシックの漢字を組み合わせて作る。

- テキストツール: クリックした所に縦書きで入り、その場で打ち直せる。
- 文字: 書体（同梱 + パソコンの書体）、大きさ、行間、字間、縦 / 横、揃え、フチ（白フチ）、色。
- 縦書き: 縦中横、禁則（行頭・行末・ぶら下げ）、部分ルビ、!? の組み。
- フキダシ: 楕円・角丸・四角・雲・トゲ・フラッシュ・ナレーション。大きさと形のハンドル、しっぽ（曲線・複数）、線の太さ、塗り、結合。
- 書体の同梱: アンチック体・明朝・ゴシック・丸ゴシック・手書き風（再配布できるもの）。
- 台詞の一覧: 読み順・話者の編集、並べ替え、削除。

### M12 コマ

**実施状況（2026-09-25）:** 実装した（`tests/test_m12.py`）。コマ ツール（F）で、ドラッグして割る（斜めも）・間の白をドラッグして動かす・角をドラッグして形を変える。テンプレート・コマ間隔・枠線・断ち切り・はみ出しはメニューとレイヤー パネルから。

- 枠線のドラッグで大きさを変える。コマ間隔（左右・上下）、枠の太さ、断ち切り。
- 斜めのコマ（傾けて割る）、多角形のコマ、枠からはみ出す絵。
- コマ割りのテンプレート（GUI から選ぶ）。

### M13 ペン・ブラシ・塗り・選択

**実施状況（2026-09-25）:** 実装した（`tests/test_m13.py`）。ブラシ パネル（左）でペンの種類・太さ・不透明度・手ぶれ補正・入り抜き・筆圧・色を選ぶ。塗りつぶし（G）・囲って塗る（Shift+G）・スポイト（I）・範囲選択（M / L / W）・線の修正（Y）と「選択」メニュー。塗りは原稿の解像度（300 dpi）のマスクで持ち、線は描き直す。

- ブラシ: G ペン、丸ペン、かぶらペン、ミリペン、鉛筆、筆、マーカー、エアブラシ、ホワイト。入り抜き、手ぶれ補正、筆圧の曲線、不透明度、サイズのパレット。
- 色: モノクロ（黒・白・グレー）とカラーのパレット、スポイト。
- 塗りつぶし（隙間閉じ、参照するレイヤー、原稿の解像度）、囲って塗る。
- 選択（長方形・投げ縄・自動選択）と移動・拡大縮小・回転・反転、コピー・貼り付け、削除。
- ベクター線の編集（つまむ、太さの修正、交点まで消す）。

### M14 定規・パース・3D

- 直線・曲線・平行線・同心円・放射線・対称の定規、グリッド、スナップ。
- パース定規（1〜3 点、アイレベル）。
- デッサン人形（画面で関節を動かす）、3D の箱。

### M15 トーン・効果線・素材

- トーン: 選択範囲・塗りつぶしの範囲に網点（線数・濃度・角度）、グラデーション、砂目、削り、重ね。
- 効果線: 集中線（中心・密度・長さ・入り抜き）、流線（角度・曲線）、ベタフラッシュ、ウニフラッシュ。
- 素材の管理: 取り込み・登録・フォルダ。

### M16 ページと作品の管理

- サムネイル付きのページ一覧、ドラッグで並べ替え、複製、見開き、ノンブル（位置・書体・隠しノンブル）。
- ストーリーエディター（全ページの台詞をまとめて編集・流し込み）。
- 入稿前の点検の表示（はみ出し・文字の重なり・解像度）。

各マイルストーンで、GUI・op・テスト・画面の確認（1280×720 と実際の操作）を行い、コミットする。
