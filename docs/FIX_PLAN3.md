# 見直し 3 回目の改修計画（H1〜H5）

3 回目の「このツールは使えない」と言う人の立場での見直し（2026-09-25）で見つかった問題を、すべて直す。
この回は単行本に近い大きさの原稿（32 ページ、各ページに線 1500 本）で測った。

---

## H1 大きな原稿での速さと、拡大したときのぼやけ

**問題（32 ページ × 線 1500 本）:**

| 操作 | 時間 |
|---|---|
| 1 本描く | 約 4.8 秒 |
| 元に戻す | 約 11 秒 |
| やり直す | 約 7 秒 |
| 開く | 約 7 秒 |
| ページをめくる | 約 2.6 秒 |

原因:
- 変更のたびに原稿全体を複製する（2.65 秒）。
- 変更のたびに原稿全体を書き直して保存する（1.5 秒）。
- 元に戻すたびに原稿全体を読み込み直す（6.5 秒）。

画面の描画は 220dpi が上限で、300% 以上に拡大するとぼやける。

**決めること:**
- **複製を減らす:** 変更で触れるページ（と見開きの相手）だけを複製する。台詞・企画などの小さな部分は今までどおり複製する。ページ構成を変える op や、どこに触れるか分からない op は、今までどおり全体を複製する。
- **保存を軽くする:** 変わっていないレイヤーの線は、前回の保存の結果（資産の参照）をそのまま使う。
- **読み込みを軽くする:** 線のまとまり（資産）ごとに、読み込んだ結果を覚えておく。元に戻す・やり直すで読み込み直すときは、変わっていないレイヤーを読み直さない。
- **開く・めくるを速く:** ページ一覧の縮小図は、見えている分から少しずつ作る。
- **拡大:** 描画の上限を 600dpi に上げる。まず軽い解像度ですぐ出し、細かい解像度はバックグラウンドで描いて、できたら差し替える。

**条件（テスト）:**
- 32 ページ × 1500 本の原稿で:
  - 1 本描く（保存を含む）: 0.6 秒以内
  - 元に戻す・やり直す: 各 1.5 秒以内
  - 開く: 3 秒以内
  - めくる: 1 秒以内
- 部分だけ複製しても、結果が全体複製と同じ。
- 400% で線がくっきりする（描画の解像度が倍率に合う）。

**実施状況（済）:** `tests/test_h1.py`。この環境で測った値（32 ページ × 1500 本）:

| 操作 | 前 | 後 |
|---|---|---|
| 1 本描く | 4.8 秒 | 0.07 秒 |
| 元に戻す | 11 秒 | 0.4 秒 |
| やり直す | 7 秒 | 0.08 秒 |
| 開く | 7 秒 | 1.2 秒 |
| めくる | 2.6 秒 | 0.5 秒 |

- 複製: `ops._working_copy`。触れるページは `_touched_pages` で決める（`PAGE_LOCAL_OPS`・台詞の op・本全体の小さな op）。分からない op は全体を複製する。線（`Stroke`）の複製は座標の組をそのまま使う。
- 保存・読み込み: `genko/blobcache.py` が線のまとまりと資産の対応を覚える。線の資産は座標を base64 に詰めた形にした（読むのが 10 倍ほど速い）。大きな op のまとまりは日誌の行に名前だけを残し、中身は資産 `ops_asset` に置く。日誌は前に読んだ所から先だけを読む。
- 要約（`snapshot`）は線を数えるだけにした。
- 画面: まず 220dpi まで（初めて見るページは線を単純な折れ線で）すぐ出し、細かい描画（〜432dpi）と本当の線はバックグラウンドのスレッドで描いて差し替える。ページが変わると描きかけは止める。600dpi はメモリが足りない（B4 で 1 枚 200MB）ので 432dpi（1 倍の画面で 450%）を上限にした。
- 縮小図（32dpi 以下）は線を単純な折れ線で描く。

## H2 画面と案内

**問題:**
- 選択ツールで台詞を選んでいないときも、使えない文字の設定欄がずらりと並ぶ。
- ヘルプに、前回足した機能（`{大|…}`、レイヤー移動、グラデーション、全体図、フキダシの揺れ・二重線、MCP の新しい道具）が書かれていない。
- 左の道具が 18 個に増え、アイコンだけでは見分けにくい。

**決めること:**
- 台詞を選んでいないときは、文字・フキダシの設定を隠し、「台詞をクリックすると、ここに文字とフキダシの設定が出ます」とだけ出す。
- ヘルプの「はじめての使い方」「困ったとき」を今の機能に合わせる。ショートカット一覧は今のままで自動。
- 表示 → 「道具の名前を表示」で、道具パレットにアイコンと名前を並べられる（設定に残る）。アイコンの形も見分けやすくする（囲って塗る・グラデーション・スポイト）。

**実施状況（済）:** `tests/test_h2.py`。`StoryPanel.style_body` は台詞を選ぶまで隠す。`act_tool_names`（設定 `ui/tool_names`）。パレットでは長い名前を短く（長方形選択・投げ縄選択・線の修正・3D）。塗りつぶしはバケツ、囲って塗るは塗った投げ縄、スポイトは球の付いた管に描き直した。ヘルプの「はじめての 1 冊」に拡大・全体図・レイヤー移動・グラデーション・部分書式・フキダシの形・印刷・AI と描くこと、「困ったとき」に 3 項目を足した。

## H3 マンガの材料

**問題:**
- 電話やテレビの声に使う「電子音（ギザギザの角のあるフキダシ）」がない。
- 書体の本当の太さ違い（見出し用の極太など）がない。
- 原稿を印刷できない。

**決めること:**
- フキダシの形 `electric` を足す（電子音。角のあるギザギザの縁、稲妻形のしっぽ）。
- 太さは `style.weight: normal | bold | heavy`（太・極太）。同梱の書体が持たない太さは、線を太らせて作る。台詞の設定に「太さ」を置く（「太字」の欄は `weight` に合わせる）。
- ファイル → 印刷…（Ctrl+P）: 印刷の窓でプリンターを選び、ページの範囲と「仕上がりで切る／用紙全体」を決めて印刷する。

**実施状況（済）:** `tests/test_h2.py`（H3 の分も）。`balloons._electric`（超楕円をのこぎり歯に）としっぽの稲妻。`style.weight` と `tategaki.weight_level`・`bold_px(em, level)`、`{極太|…}`、style_runs の `weight`。台詞の設定の「太さ」（標準・太・極太）。`app/printing.py`（`PrintDialog`・`print_pages`、印刷と同じ見え方で用紙に合わせる。「裁ち落としまで」も選べる）。

## H4 似たツールと比べて

**問題:**
- 背景の 3D 素材（部屋・教室・廊下・街並み）がない。
- 塗りつぶしの「参照レイヤー」を好きなレイヤーに指定できない。
- 同じ操作をまとめて繰り返す機能（オートアクション）がない。

**決めること:**
- **背景の 3D:** `add_scene {kind: room | classroom | corridor | street, pos, size, rot, focal_mm}`。箱・床・円柱を組み合わせた背景の下書きをまとめて置き、`scene` の id でまとめて動かし・消し・線にする。
- **参照レイヤー:** `set_layer {reference: true}`。塗りつぶしの `reference: "reference"` は、参照に指定したレイヤーの線を見て塗る。レイヤー パネルに「参照にする」、塗りの設定に「見る範囲: 参照レイヤー」を置く。
- **オートアクション:**
  - 「記録を始める／止める」の間にした操作（op）を名前を付けて残し（設定フォルダの `actions.json`）、今のページと描く先のレイヤーで何度でも実行する。
  - メニュー ファイル → オートアクション（記録を始める・止めて名前を付ける・実行・消す）。

**実施状況（済）:** `tests/test_h4.py`。
- 背景: `add_scene` は `kind: "scene"` の 1 つの 3D（`prim3d.scene_parts` が壁・床の格子・窓・扉・机・建物・電柱を作る）。部屋と教室は中から斜めに、廊下と街並みは奥へ向かう一点透視で置く（`SCENE_VIEWS`）。`edit_prim`・`delete_prim`・`trace_prims` は id 1 つでまとめて効く。メニュー 定規・3D → 背景の 3D を置く、3D ツールの設定にも。
- 参照レイヤー: `Layer.reference`・`set_layer {reference}`、塗り（`fill`・`add_tone` の `at`）の `reference: "reference"`。レイヤー パネルの「参照にする」と〔参照〕の印、塗りの「見る範囲: 参照レイヤー」。
- オートアクション: `app/actions.py`（`record`・`replay`・設定フォルダの `actions.json`）。実行した分は 1 回の「元に戻す」で戻る。記録中は下の欄に「● 記録中」。

## H5 MCP

**問題:**
- 素材を貼れる（`stamp_material`）のに、素材の一覧を知る手段がない。
- 使える書体とブラシの一覧を返す道具がない。
- 原稿の要約でレイヤーの名前・種類・不透明度・合成・マスク・表示色・フォルダが分からない。
- `render` で 1 つのレイヤーだけ、あるいは印刷と同じ見え方だけを確かめられない。

**決めること:**
- `inspect` の `target`: `materials`（素材の一覧: id・名前・種類・フォルダ）、`fonts`（同梱の書体とパソコンの書体）、`brushes`（入っているブラシと、原稿・自分の自作ブラシ）。
- 要約（`snapshot`）のレイヤーに `title`・`kind`・`opacity`・`blend`・`clip`・`locked`・`mask`・`color`・`parent_id`・`reference` を足す。台詞の `style`・`balloon`・`wrap` も出す。
- `render` に `layer_id`（そのレイヤーだけ）と `mode: print`（印刷と同じ見え方）を足す。
- 案内書（`SKILL.md` と写し、`AGENT.md`）に書く。
