# 「使えない」と言われる問題を直す計画（F1〜F6）

2026-09-25 の見直し（画面を撮って確かめた）で見つかった問題を、すべて直すための計画。
M10〜M16 と同じく、GUI・op・テスト・画面の確認（1280×720 と 1024×640）を各段階で行い、段階ごとにコミットする。

進め方の原則:

- 一人で描く人がエージェント無しでも迷わず使えることを最優先にする。承認の仕組みはエージェントと進める原稿（`strict_gates` / studio）では今のまま必須。
- 既存の原稿はそのまま開けて、見た目が変わらないこと（読み込み時に移行する）。
- 数値で確かめられるものは、テストで確かめる（寸法・画面の広さ・反応の速さ・訳の抜け）。

| 段階 | 内容 | 直す問題（見直しの番号） |
|---|---|---|
| F1 | 原稿用紙を業界の寸法に | 致命 1、材料（同人誌の用紙） |
| F2 | 作業を止めない（承認の壁・英語・止まる窓） | 致命 2・6 |
| F3 | 画面の配置と導線・項目名 | 致命 3、操作感・導線のすべて、メニューと項目名のすべて |
| F4 | 描き味（描いている最中の線・ペンの消しゴム・表示の回転と反転） | 致命 4・5、操作感（回転・反転） |
| F5 | マンガの材料（傍点・回転・フキダシペン・縦書きの欧文） | 材料の不足 |
| F6 | 機能の不足（レイヤー・自由変形・ブラシの自作・書き出し・履歴・ヘルプ・環境設定） | 機能比較・操作感（履歴・ヘルプ・環境設定） |

## F1 原稿用紙を業界の寸法に

**実施状況（2026-09-25）:** 実装した（`tests/test_f1.py`）。用紙・仕上がり・裁ち落とし・基本枠（上・下・のど・小口）を分けて持ち、B4 商業誌・投稿、B5／A5 同人誌、A4 練習、Webtoon、自分で決めるを用意。書き出しは用紙全体（トンボ付き）・裁ち落としまで・仕上がりまでを選べる。「ページ → 原稿用紙の設定…」で既存の原稿の用紙を変え、中身を新しい基本枠に合わせて動かせる。既存の原稿は描画が変わらない（テストで 1 ピクセル単位で確認）。

**問題:** B4 の原稿で用紙全体を仕上がりとして扱っている（仕上がり 251×358 mm、基本枠 231×338 mm）。商業誌・投稿用の B4 原稿は仕上がり約 220×310 mm、基本枠 180×270 mm、裁ち落とし 5 mm。同人誌の用紙が無い。基本枠の余白が上下左右で同じ幅しか持てない。

**決めること（設計）:**

- 1 ページの持ち物を「用紙（キャンバス）」「仕上がり（トンボの内側）」「裁ち落とし（仕上がりの外の幅）」「基本枠（仕上がりの中、上・下・のど・小口の余白）」に分ける。座標の原点は用紙の左上。
  - `PageSpec` に `trim_w_mm` `trim_h_mm`（仕上がり、用紙の中央）、`frame_margins_mm = {top, bottom, inner, outer}`（仕上がりから基本枠まで。のど・小口はページの左右で入れ替わる）を足す。`width_mm` `height_mm` は用紙、`bleed_mm` は仕上がりの外の幅。
  - `Page.paper_rect_mm()` `trim_rect_mm()` `bleed_rect_mm()` `inner_rect_mm()`（基本枠。左右ページで のど／小口 を入れ替える）を置き、寸法を使う 15 ファイル（render・export・psd・profiles・pack・nombre・checks・canvas・placement・atari など）を全部これに合わせる。
- 用紙の見本（新規作成で選ぶ）:

  | 名前 | 用紙 | 仕上がり | 裁ち落とし | 基本枠 |
  |---|---|---|---|---|
  | B4 商業誌・投稿（600 dpi） | 257×364 | 220×310 | 5 | 180×270 |
  | B5 同人誌（原寸・600 dpi） | 用紙は仕上がり＋余白 | 182×257 | 3 | 150×220 |
  | A5 同人誌（原寸・600 dpi） | 同上 | 148×210 | 3 | 120×180 |
  | A4 モノクロ（練習） | 210×297 | 210×297 | 3 | 180×270 |
  | 縦読み（Webtoon） | 今のまま | | | |
  | 自分で決める… | すべて数値で指定 | | | |

  数値は出版社・印刷所で違うため、見本は目安として出し、「自分で決める」と「原稿の設定を変える…」で直せるようにする。
- 書き出し: 入稿用（PDF・TIFF・PSD）は「裁ち落としまで」または「仕上がりまで」を選べる（トンボ付きは用紙全体）。画面用（縦読み・SNS）は仕上がりで切る。
- 既存の原稿: 読み込み時に「仕上がり＝用紙−裁ち落とし×2、余白＝今の内側の余白」として移行し、見た目を変えない。
- 「ページ → 原稿の設定を変える…」と op `set_page_spec {preset | 数値, relayout: true}`: 用紙を変えると、コマ割り・台詞・絵を新しい基本枠に合わせて並べ直す（比率で移す）。

**できたと言える条件（テスト）:**

- B4 商業誌の見本で、仕上がり 220×310、基本枠 180×270（中央）、裁ち落とし 5 mm。
- 左右のページで、のど・小口の余白が入れ替わる。
- PDF の 1 ページの大きさ（裁ち落としまで／仕上がりまで）が選んだとおり。
- ノンブル・点検・ガイド線・新しいコマが、新しい寸法で正しい所に出る。
- 移行した既存の原稿で、描画が 1 ピクセルも変わらない。

## F2 作業を止めない

**実施状況（2026-09-25）:** 実装した（`tests/test_f2.py`）。一人の原稿（`strict_gates` も studio も無い原稿）では、ネームの承認前でもペン入れ・塗り・読み込んだ線画の変換ができる。op・定規・トーン・効果線・ノンブル・用紙・保存と取り消しのエラー 130 種すべてに日本語の文を付け、訳の抜けはテストで見つかる。作業中のエラーは下の欄に赤い「⚠」のお知らせで出し（6 秒）、窓で止めるのは消す前の確認だけにした。

**問題:** 一人で描いていても、ネーム完了を押すまでペン入れのレイヤーに描けず、「ネームの承認（ネームOK）…」という専門用語の窓で止められる。エラー 105 種のうち 84 種が英語のまま出る。どのエラーも OK を押すまで作業が止まる。

**決めること:**

- 承認の壁（ネーム→作画→仕上げの順番）は、エージェントと進める原稿（`strict_gates` または studio）だけにかける。一人の原稿では、どのレイヤーにもいつでも描ける（段階は「作業中」の目印として残す）。op の決まりもそう変える。エージェントの原稿のときだけ、承認を待つ理由を日本語で説明する。
- エラー文: op のすべての `ApplyError` に日本語の訳を付ける。訳のないエラーが残っていたらテストが落ちるようにする（ops.py の raise を全部読んで確かめる）。
- 出し方: 画面の下に出る「お知らせ帯」（赤・6 秒、クリックで詳細）に変え、作業を止めない。窓で聞くのは、取り消せない操作の確認（削除など）だけにする。

**条件:**

- 一人の原稿で、新規作成してすぐペン入れのレイヤーに描ける。
- エージェントの原稿では今までどおり止まり、理由が日本語で出る。
- 訳のないエラーが 0（テスト）。
- 描画・塗り・選択の操作から、止まる窓が出ない（テストで窓を禁止して確かめる）。

## F3 画面の配置と導線・項目名

**実施状況（2026-09-25）:** 実装した（`tests/test_f3.py`）。左端にアイコンの道具パレット（Genko が自分で描いたアイコン）、その右に持っている道具で中身が変わる「ツールの設定」、中央にキャンバス、右に上段（ページ・レイヤー）と下段（台詞・素材・定規・3D・点検）の 2 段のタブ。承認箱・コマの詳細・資料はエージェントと進める原稿のときだけ、ツールの設定の下に出る。一人の原稿では工程の帯とステータスの工程名・利用者名も出さない。キャンバスは 1280×720 で 768 px、1024×640 で 512 px。1024×640 でどのパネルも右端が切れない（テストで全道具・全パネルを見る）。ウィンドウは画面より高くならず、長いパネルはスクロールする。「コマ割り」「3D 操作」に改名し、ツールメニューに定規・3D・効果線・素材を置くを揃え、同じ名前の項目の重なりを無くした。

**問題:**

- 1280×720 でキャンバスが画面の約 3 分の 1（1024 幅では約 300 px）しかない。
- 右は承認箱が最初に開いている。右のタブ 8 つの名前が切れる。
- 台詞パネルの右端（削除・書体）が切れる。
- ツールバーが文字だけで横長。
- 道具を持ち替えても設定の欄が変わらない。
- ステータスにエージェント用の表示（ネーム未提出・利用者名）が出る。
- 項目名が重なっている（「コマ」、「3D」の中の「3D」）。
- 道具がツールメニューに揃っていない。「ペンの色…」が二重。

**決めること:**

- **配置**（CLIP STUDIO の並びに寄せる）:
  - 左端: 縦の道具パレット。アイコン付きで、ツールチップにショートカットを出す。
  - 左: 「ツールの設定」（持っている道具で中身が変わる）。
  - 中央: キャンバス。
  - 右: よく使うパネル（レイヤー・台詞・素材）。
  - ページ一覧: 下または右にたためる帯（サムネイルだけ・切り替えのキー付き）。
- **承認箱・コマの詳細・ライブラリ**: エージェントの原稿のとき、または依頼が届いたときだけ出す。
- **目標の広さ**: キャンバスは 1280×720 で幅の 60% 以上（760 px 以上）、1024×640 で 500 px 以上。
- **ツールの設定の中身（道具ごと）**:
  - ペン・消しゴム: ブラシ。
  - 塗りつぶし: 隙間・見る範囲。
  - テキスト: 書体・大きさ・フキダシの種類・縦横。
  - コマ割り: 間隔・枠線。
  - 定規: 種類と数値。
  - 3D 操作: ポーズ・向き。
  - 効果線: 種類と数値。
  - 範囲選択: 変形の数値。
- **アイコン**: Genko で描いた SVG を同梱する（他所の画像は使わない）。上のツールバーはコマンド（元に戻す・拡大・ページ移動・書き出し）だけにして短くする。
- **パネル**: どのパネルも幅 260 px で切れないように並べ直す。タブの名前は短くして切れないようにする。
- **ステータス**: 一人の原稿では、エージェント用の表示（ネーム未提出・承認箱の数・利用者名）を出さない。
- **項目名**:
  - 道具の「コマ」→「コマ割り」、パネルの「コマ」→「コマの詳細」。
  - 「3D」→「3D 操作」。
  - 「ツール」メニューに全部の道具を揃える（定規・3D 操作・効果線も）。
  - 「ペンの色…」はツールの設定の色を開く 1 つにまとめる。
  - メニューの全項目の名前と重なりを表で見直す（重なり 0 をテストする）。

**条件（テスト）:**

- 1280×720 と 1024×640 で、キャンバスの幅が目標以上。
- どのパネルも幅 260 px のとき、中の部品がはみ出さない（全部品の位置を調べる）。
- タブの名前が切れない。
- 道具を持ち替えると、ツールの設定の中身が変わる。
- 一人の原稿では承認箱が出ない。
- メニューに同じ名前の項目が無い。

## F4 描き味

**実施状況（2026-09-25）:** 実装した（`tests/test_f4.py`）。描いている最中の線は、ブラシ パネルのペン（種類・太さ・色・不透明度・筆圧の効き）で `genko.brushes.draw` により画面の解像度で描き、増えた区間だけ描き足す（`app/live_ink.py`。1 動き平均 16 ms 未満、線が長くなっても重くならない。確定後の線と 9 割以上重なる）。定規のスナップや Shift の直線、対称の写しはその形で描き直す。ペンの後ろ側（消しゴム）はその 1 本だけ消しゴムになり、離すとペンに戻る。表示の回転（表示メニューの 15° 回転・Ctrl+Alt+←/→、Shift＋スペースでドラッグ、Ctrl で 15° 刻み）と左右反転（H）は表示だけで、描画は 1 つの変換（`_view`）を通し、入力はその逆（`_ev`）で原稿の座標に戻す。下の欄に回転の角度と反転を出す。

**問題:**

- 描いている最中は太さの変わらないオレンジの線で、離すまで本当の線が見えない。
- ペンの後ろ側（消しゴム）でも描いてしまう。
- 表示の回転・左右反転が無い。

**決めること:**

- **描いている最中の線**: 仕上がりと同じ描き方（`genko.brushes.draw`、筆圧・色・不透明度・ブラシの種類）で、画面の解像度の重ね絵に少しずつ描き足す（増えた区間だけ描く）。離したときの入り抜きだけは、確定の描き直しで付く。
  - 目標: ペンの 1 動きあたり 16 ms 以内（1280 幅・100%）。
- **ペンタブレット**:
  - ペンの後ろ側（Eraser）では、道具を消しゴムに一時的に切り替える。
  - ペンのボタンは、環境設定で「スポイト／手のひら／右クリック」を割り当てられるようにする（F6）。
- **表示の回転と左右反転**:
  - 回転は Shift＋Space を押しながらドラッグ、または「表示 → 回転（±15°・元に戻す）」。左右反転表示は H。
  - 表示の座標変換を 1 か所にまとめ、重ね絵（ハンドル・定規・選択範囲・3D）も全部それに従わせる。
  - 回転・反転は表示だけで、原稿は変わらない。

**条件:**

- 描いている途中の重ね絵が、確定後の線と太さ・色でほぼ一致する（比べるテスト）。
- 1 動きの処理時間が目標以内（テストで測る）。
- ペンの後ろ側の入力で線が消える。
- 回転・反転した表示で描いた線が、指した所に入る（座標のテスト）。

## F5 マンガの材料

**実施状況（2026-09-25）:** 実装した（`tests/test_f5.py`）。
- 傍点: 台詞の入力（台詞パネル・その場の入力・テキストツール・ストーリーエディター）で `《《強調》》` と書くと付く（`emphasis_runs`）。縦書きは文字の右、横書きは上。ルビがあるときはルビを外側にずらす。印はゴマ（﹅）か黒丸（・）を `style.emphasis_mark` で選ぶ。
- 回転と傾き: `style.rotate_deg` でフキダシごと回す（しっぽの先は元の場所を指したまま）。選択ツールでフキダシの上の○をドラッグして回せる（Shift で 15° 刻み）。`skew_deg`（傾き）と `arc`（弓なり、-1〜1）で描き文字を傾け・曲げる。台詞パネルに回転・傾き・弓なり・欧文・傍点の欄を足した。
- フキダシペン: テキストの道具の設定の「フキダシを手で描く」で、ドラッグで囲んだ形がフキダシになり、続けて台詞を打つ。描いた形（`path`）は今まで保存されるだけで描かれていなかったので、描くようにした。箱は形の外接枠になる。しっぽ・線の太さ・塗りも効く。`set_balloon_path` に null で元の形に戻る。
- 縦書きの欧文: 半角の英数字が 4 文字以上続くと寝かせて組む（2〜3 文字は縦中横のまま）。`style.latin: upright` で 1 文字ずつ立てる。

**問題:**

- 傍点（圏点）が無い。
- 文字・フキダシを回せない・傾けられない（描き文字の効果音）。
- フキダシを手で描けない（仕組みはあるが画面から使えない）。
- 縦書きの中の長い英数字が回らない。

**決めること:**

- **傍点**:
  - 台詞の入力で `《《強調》》`（小説投稿サイトと同じ書き方）と書くと、その文字に傍点が付く。
  - 印は「・」「﹅」から選べる。
  - op では `edit_line {emphasis_runs}`。
  - 縦書きは右、横書きは上に付く。ルビと重なるときは、ルビを外側にずらす。
- **回転と傾き**:
  - 台詞の `style.rotate_deg`（フキダシごと回す）を足す。効果音（sfx）には `skew_deg` と `arc`（弓なり）も足す。
  - 画面では、選んだフキダシに回すハンドルを出す（Shift で 15° 刻み）。
- **フキダシペン**:
  - テキストの道具の設定に「フキダシを描く」を置き、ドラッグで描いた形がフキダシの形になる（既存の `set_balloon_path`）。
  - 描いた形にもしっぽ・線の太さ・塗りが効く。
- **縦書きの欧文**:
  - 半角の英数字が 4 文字以上続くときは、横に寝かせて組む（2〜3 文字は今の縦中横のまま）。
  - 台詞ごとに切り替えられる（`style.latin: rotate | upright`）。

**条件（テスト）:**

- 傍点の位置が文字ごとに合う（縦・横、ルビあり）。
- 回したフキダシの中の文字が枠からはみ出さない。
- 描いた形のフキダシが保存・読み込みで残る。
- 4 文字以上の英数字が寝る。

## F6 機能の不足

**実施状況（2026-09-25）:** 実装した（`tests/test_f6.py`）。
- レイヤー: `duplicate_layer`、`merge_down`（ペン同士は線のまま、ほかは見えたとおりの絵にして結合）、「下描き（書き出さない）」、`set_layer_mask`・`paint_mask`（選択範囲から作る・全部見せる・反転・使わない・消す、マスクの編集中はペンで見せて消しゴムで隠す）、`set_layer {color}`（画面だけの表示色）、レイヤー一覧の小さな絵。
- 自由変形: `transform_area {warp: perspective | mesh}`（`genko/warp.py`）。線は点ごと、塗り・絵は小さな三角形ごとに写す。画面では 4 隅・3×3 の点を引っぱり、Enter で確定。
- ブラシの自作: 「ブラシを複製して調整…」（試し描き付き）。設定フォルダの `brushes.json` に残し、描いた原稿には `define_brush` で定義を写す（別のパソコンでも同じに描ける）。
- 書き出し: ページの範囲（全部・今のページ・今の見開き・範囲指定）、1 ページ目のプレビュー、書き出す前の点検（止まる問題があれば「このまま書き出す／直す／やめる」）。
- 履歴パネル: 保存済みの変更と作業中の変更を日本語の名前で並べ、クリックでその時点へ戻る・進む（編集 → 履歴…、Ctrl+H）。
- ヘルプ: ショートカット一覧（今のキーから作る、F1）、はじめての使い方、困ったとき、Genko について。
- 環境設定（ファイル → 環境設定…、Ctrl+,）: ショートカットの変更（重なりは断る）、筆圧の試し書きで曲線を合わせる、ペンのサイドボタン（右クリック・スポイト・手のひら）、画面の文字の大きさ、新しい原稿の用紙、保存までの間隔。

**問題:**

- レイヤーの複製・下と結合・印刷しない下描き・マスク・小さな絵・色が無い。
- 自由変形（遠近・メッシュ）が無い。ブラシを自作できない。
- 書き出しでページの範囲を選べない。書き出しの前に点検が出ない。
- 履歴が見えない。ヘルプ・ショートカット一覧・環境設定が無い。

**決めること:**

- **レイヤー**:
  - 複製（`duplicate_layer`）、下と結合（`merge_down`：ペン同士は線をそのまま合わせ、ペイントとは絵にして合わせる）。
  - 「下描き（書き出さない）」の切り替え（`set_layer {exportable}` をパネルに出す）。
  - レイヤーマスク（`set_layer {mask}`：選択範囲からマスクを作り、ペンで足し消しゴムで削る）。
  - レイヤーの小さな絵、レイヤーの表示色（下描きを青で見るなど）。
- **自由変形**:
  - 選択範囲の変形に「遠近（4 隅）」と「メッシュ（3×3）」を足す。
  - 線は点ごとに写し、塗り・絵は PIL の遠近・メッシュ変換で写す。
  - op は `transform_area {perspective | mesh}`。
- **ブラシの自作**:
  - 「ブラシを複製して調整」の窓で、入り・筆圧の最小・曲線・質感・固定の太さ・色を変える。
  - 自作のブラシは設定フォルダに保存する。使った原稿には、その定義を原稿の中にも写す（他のパソコンでも同じに描ける）。
- **書き出し**:
  - ページの範囲（全部・今のページ・範囲指定・見開き単位）を選べる。
  - 1 ページ目のプレビューを出す。
  - 書き出す前に「入稿前の点検」を自動で行い、止まる問題があれば一覧を見せてから「このまま書き出す／直す」を選ぶ。
- **履歴パネル**: 元に戻す単位ごとに日本語の名前（「ペンで描いた」「コマを割った」…）で並べ、クリックでその時点まで戻る・進む。
- **ヘルプ**:
  - 「ヘルプ」メニューに、ショートカット一覧（今の設定から自動で作る）、はじめての使い方（ネーム→ペン入れ→写植→トーン→書き出しの 1 枚の案内）、困ったとき（よくある質問）を置く。
- **環境設定**:
  - ショートカットの変更（重なりを検査する）。
  - ペンタブレット（筆圧の試し書きで曲線を合わせる、ペンのボタンの割り当て）。
  - 画面の文字の大きさ、新規作成の既定の用紙、自動保存の間隔。

**条件（テスト）:**

- 複製・結合の前後で描画が同じ。
- 下描きのレイヤーは書き出しに出ない。
- マスクで隠れる。
- 遠近変形で 4 隅が指定どおりに移る。
- 自作のブラシが別の設定フォルダでも同じに描ける。
- 範囲を選んだ書き出しのページ数が合う。
- 点検の結果が書き出しの前に出る。
- 履歴のクリックで、その時点の原稿に戻る。
- ショートカットを変えると、メニューと一覧に反映される。

## 順番と理由

1. **F1**: 寸法はコマ割り・写植・ノンブル・書き出しの土台で、後から変えると全部やり直しになるため、最初に行う。
2. **F2**: 一人で描く人が最初の 1 分で止められる壁を取る。
3. **F3**: 以降の道具（F4〜F6）を置く場所（道具パレット・ツールの設定・パネルの並び）を先に決める。
4. **F4**: 描く道具としての基本の感触。
5. **F5**: 写植の材料。
6. **F6**: 残りの機能の不足。

各段階の終わりに、同じ見直し（「使えない」と言う人の立場での確認、1280×720・1024×640 の画面、実際の操作の流れ）をやり直し、見つかったものを次の段階に足す。
