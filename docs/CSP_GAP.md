# CLIP STUDIO PAINT EX との差の一覧（完成の基準）

2026-09-25 作成。CLIP STUDIO PAINT EX（以下 CSP）の機能を分野ごとに並べ、Genko の今の状態と、どの段階で埋めるかを書く。
**この一覧が完成の基準**。見直しでは、この表の「無」「一部」が残っていないか、「有」が本当に使えるかだけを確かめる。
表にない指摘は、まず表に足してから直す（見直しのたびに基準が変わらないようにする）。

状態: **有**（同じことができる）／**一部**（できるが足りない所がある。足りない所を書く）／**無**／**対象外**（理由を書く）。
段階: J1〜J12（下の「段階」）。
