# GUI の手動チェックリスト（M7）

自動試験（`tests/test_m7_gui.py`、offscreen）では確かめられない、人の目と手の確認。結果は `docs/eval/` に日付で残す。

準備: エージェント（または `tests/agents` の偽エージェント）で、ネーム承認の依頼・設定画の候補・1 ページ分の作画候補・相談がある状態のプロジェクトを用意し、`genko app PROJ` で開く。

## 起動と表示

- [ ] 引数なしの `genko app` で起動画面が出て、最近の原稿（作品名と場所）を開ける
- [ ] 「新しい原稿を作る…」で作品名・ページ数・原稿用紙・綴じ・場所を選んで作れ、すぐ開く
- [ ] 1280×720 の画面（ノート PC）でウィンドウが画面に収まり、承認箱のボタンまで見える
- [ ] 左端の道具アイコンを押すと、その右の「ツールの設定」が持ち替えた道具の設定（ペンならブラシ、テキストならフキダシ・書体、コマ割りならコマの操作）に変わる
- [ ] 一人の原稿では承認箱・工程の帯が出ず、エージェントの原稿ではツールの設定の下に承認箱が出る
- [ ] 1024×640 でもパネルのボタン・名前が右端で切れず、タブの名前が全部読める
- [ ] ペンタブレットで描いている最中から、選んだペンの太さ・筆圧・色で線が見え、遅れを感じない
- [ ] ペンの後ろ側（消しゴム）でなぞると線が消え、ペン先に戻すとまた描ける
- [ ] 表示 → 右に回す／左右反転（H）で回した画面でも、ペン先の所に線が入る。「回転・反転を戻す」で元に戻る
- [ ] 開いたときにページ全体が見える。Ctrl+0 で全体、Ctrl+1 で紙の大きさ、Ctrl+ホイール（トラックパッドのピンチ）で拡大縮小
- [ ] ホイール・2 本指で表示が動く。スペース＋ドラッグ、選択ツールで紙をドラッグしても動く
- [ ] 選択ツール（V）でコマをクリックすると選ばれ、フキダシをドラッグすると動く。ペン（B）の時だけ線が引ける
- [ ] 編集画面のフキダシが縦書きで、印刷と同じ見た目になっている（拡大しても少し待つとくっきりする）
- [ ] コマを右クリックすると、割る・結合が出る
- [ ] ページ削除は確認が出る。Ctrl+Z で戻り、Ctrl+Shift+Z（Ctrl+Y）でやり直せる
- [ ] 画面の文字が日本語で、内部の id や英語の状態名（stage=… など）が出ていない
- [ ] 工程の件数（下の帯）が review.html の内容と合っている

## 描く（M10）

- [ ] ペンで線を引くと、すぐ（引っかからずに）出る。タブレットの筆圧で太さが変わる
- [ ] レイヤー パネルで選んだレイヤーに描ける（「描く先」の表示と一致する）。ロックしたレイヤーには描けず、理由が出る
- [ ] 消しゴムでペンの線が切れる。[ ] で消しゴムとペンの太さが変わる
- [ ] レイヤーの追加（ペン・ペイント・フォルダ）、名前の変更、↑↓、不透明度、削除（確認あり）ができる
- [ ] 台詞パネルで、選んだコマの右上に縦書きで台詞が入り、次の台詞はその左に入る。種類・縦横を変えて「この台詞を直す」、削除ができる
- [ ] フキダシをクリックすると台詞パネルの一覧でも選ばれ、ダブルクリックで台詞パネルが開く
- [ ] 「画像を読み込む…」で、選んだコマに画像が入る（コマを選んでいなければページ全体）
- [ ] 仕上がり線（赤紫）・裁ち落とし（灰色の帯と点線）・印刷されない用紙の余白（濃い灰色）・基本枠（青の点線）が見え、表示メニューで消せる
- [ ] 新しい原稿で、原稿用紙（B4 商業誌・投稿／B5・A5 同人誌／A4 練習／縦読み／自分で決める）を選ぶと、寸法（用紙・仕上がり・裁ち落とし・基本枠）が下に出る
- [ ] 「ページ → 原稿用紙の設定…」で見本か数値を選んで変えると、コマ・台詞・絵が新しい基本枠に合わせて動き、元に戻すで戻る
- [ ] 書き出しで「書き出す範囲」（用紙全体・裁ち落としまで・仕上がりまで）を選べ、用紙全体ではトンボが入る
- [ ] 左右のページで、のど・小口の余白が入れ替わる（余白を左右で違う値にしたとき）
- [ ] 600 dpi の書き出しで、線とコマ枠がギザギザにならず、指定の太さで出る

## 写植（M11）

- [ ] テキストツール（T）でクリックした所に入力欄が出て、Ctrl+Enter で縦書きの台詞になる（Esc でやめる）
- [ ] ｜約束《やくそく》と打つと、約束の右にルビが付く。「12」「!?」が縦中横になる
- [ ] フキダシをダブルクリックすると打ち直せ、フキダシの中心は動かない
- [ ] 選んだフキダシの四隅・辺の□で大きさ、●でしっぽの先、◇でしっぽの曲がりを変えられる
- [ ] 右クリックで形（11 種）、しっぽを足す・消す・まっすぐにする、次の台詞とつなげる・離す、縦横の切り替え、削除ができる
- [ ] 台詞パネルで書体（アンチック・ゴシック・明朝・丸ゴシック・手書き風・効果音 2 種・パソコンの書体）、大きさ、字間、行間、揃え、白フチ、線の太さ、塗り、文字の色を変えられ、すぐ画面に出る
- [ ] 台詞の読み順を ↑↓ で入れ替えられる
- [ ] 句読点・閉じ括弧が列の頭に来ない、開き括弧が列の末尾に来ない

## コマ（M12）

- [ ] コマ ツール（F）で、コマの中（または余白から）をドラッグすると、その線で割れる。ほぼ水平・垂直なら吸い付き、Alt を押すと自由な角度
- [ ] コマの間の白にマウスを載せると形が変わり、ドラッグで間隔の位置が動く（中のコマも追従する）
- [ ] 選んだコマの角（○）をドラッグして形を変えられ、「コマ → 選んだコマの形を元に戻す」で戻る
- [ ] 「コマ間隔の設定…」の上下・左右の間隔が、次に割るコマに使われる
- [ ] 枠線の太さ・枠線なし・断ち切りをメニューから変えられる
- [ ] 「テンプレートでコマを割る…」で見本を見て選べ、台詞とコマが作り直される（元に戻すで戻る）
- [ ] 斜めのコマでも、描いた線・読み込んだ絵がコマの形で切り取られる。レイヤーの「コマの外にもはみ出す」で間の白まで描ける

## ペン・塗り・選択（M13）

- [ ] ブラシ パネルでペンの種類（G ペン・丸ペン・かぶらペン・ミリペン・鉛筆・筆・マーカー・エアブラシ・ベタ塗りペン・ホワイト）を選ぶと、描いた線がその描き味になる。種類ごとに太さ・不透明度・手ぶれ補正・入り抜き・筆圧を覚えている
- [ ] 太さのボタン（0.2〜10 mm）と [ ] で太さが変わり、ペン先の円も変わる
- [ ] 色のパレット（黒・グレー・白・カラー）と色の四角（色を選ぶ）で色が変わる。スポイト（I）でクリックした所の色を拾える
- [ ] 塗りつぶし（G）で線に囲まれた所が塗れる。少し切れた線でも「隙間を閉じる」の幅までなら漏れない。漏れてもコマの外には出ない
- [ ] 「見る範囲」を「このレイヤーだけ」にすると、他のレイヤーの線を無視して塗れる
- [ ] 囲って塗る（Shift+G）でドラッグで囲んだ所が塗れる
- [ ] 範囲選択（M・長方形 / L・投げ縄 / W・自動選択）で選び、中をドラッグで移動、□で拡大縮小、○で回転できる（Shift で 15° 刻み・縦横比を保つ）
- [ ] 「選択」メニューで左右・上下反転、コピー・切り取り・貼り付け（新しいレイヤーに）、消す（Delete）、選択範囲を塗る、線の太さを変える、選択を解除（Ctrl+D / Esc）ができる
- [ ] 線の修正（Y）で線をつまんでドラッグすると、その辺りが滑らかに曲がる
- [ ] ブラシ パネルの「消しゴムで交点まで消す」を入れると、はみ出した線が交点まで一度に消える
- [ ] 元に戻す（Ctrl+Z）で、塗り・移動・貼り付けが戻る

## 定規・パース・3D（M14）

- [ ] 「定規」メニューで直線定規を選び、ドラッグで置ける。近くでペンで描くと定規に沿った直線になり、描いている間も沿った線が見える
- [ ] 曲線定規（クリックで点、ダブルクリックか Enter で終わり）、平行線、同心円（Alt で楕円）、放射線（クリック）、パース（1〜3 点。紙の外の灰色の所もクリックできる）、対称（左右・回転）を置ける
- [ ] 定規ツール（R）で定規の□をドラッグして動かせ、Delete で消せる
- [ ] 「定規にスナップ」（Ctrl+2）を切ると自由に描け、入れると沿う。「定規を表示」で隠せる
- [ ] 「定規・3D」パネルで定規のチェックを外すと効かなくなる。角度・楕円の比・写しの数を変えられる。「選んだコマの中だけで効かせる」で他のコマでは自由に描ける
- [ ] 対称定規で描いた線が反対側（回転なら全部の向き）にも描かれる
- [ ] 「グリッドを表示」「グリッドにスナップ」「グリッドの間隔…」が効き、Shift で引く直線の端がグリッドに吸い付く
- [ ] 「3D → デッサン人形を置く」で選んだコマに人形が出る。3D ツール（J）で手・肘・膝・足・頭・胸の○をドラッグするとその向きに曲がり、腰の○（や体）をドラッグで動く。ポーズのメニューで立つ・歩く・走る…に変わる
- [ ] 「3D の箱を置く」で箱が出て、中の○で動き、上の○を左右・上下にドラッグで回る。パネルの向き・傾き・大きさ・パースで変わる
- [ ] 「3D を線にする」で描く先のレイヤーに鉛筆の線で写せる。人形と箱は書き出しには出ない

## トーン・効果線・素材（M15）

- [ ] 範囲選択かコマを選び、素材パネルでトーンを選んで「貼る」（または Ctrl+Shift+T）で、そこにトーンが入る。描く先がそのトーンになる
- [ ] 「クリックした所にトーンを貼る」で、線で囲まれた所をクリックするとそこにトーンが入る
- [ ] トーンが描く先のとき、ペンでトーンを足せ、消しゴムで削れる（「消しゴムでぼかして削る」でぼかし）
- [ ] 素材パネルのトーンの欄で、模様（網点・線・カケアミ風・砂目・グレー）・線数・濃さ・角度・グラデーション（直線・円、向き・始まり・終わり）を変えるとすぐ変わる
- [ ] 画面ではグレー、書き出し（PDF など）では網点になる。上のレイヤーの白で隠せる
- [ ] 「トーン・効果線」メニューで集中線・流線・ウニフラッシュ・ベタフラッシュを選び、コマの中をクリックすると入る（集中線とフラッシュはそこが中心）。中心の＋をドラッグで動かせる
- [ ] 素材パネルの効果線の欄で本数・中心の空き・ばらつき・太さ・長さ・向き・曲がりを変えられ、「線にする」で描く先のレイヤーのペン線になって消しゴムで手を入れられる
- [ ] 素材パネルで、フォルダごとに素材がサムネイルで並ぶ。「画像を取り込む…」で画像を素材にし、クリックした所に置ける
- [ ] 範囲選択して「選択範囲を登録…」で、描いた線をパーツとして登録し、別の所・別の原稿に置ける
- [ ] 自分の素材の名前・フォルダを変え、消せる（最初から入っている素材は消せない）

## ページと作品（M16）

- [ ] 左のページ一覧にページの小さな絵が出て、描くと少し後に更新される
- [ ] ページをドラッグ（または Ctrl+Shift+↑↓・右クリックの「前へ／後ろへ移す」）で並べ替えられ、台詞も一緒に動く
- [ ] 右クリックで「この後ろにページを追加」「複製」「見開きにする／解除」「ノンブルを隠す／出す」「削除」ができる
- [ ] 「ページ → ノンブルの設定…」で位置（下の真ん中・下の外側・上の外側・外側の真ん中）、書体、大きさ、始まりの番号、隠しノンブルを変えられ、校正・書き出しに出る
- [ ] 「ストーリーエディター…」（Ctrl+Shift+L）で全ページの台詞が表で出て、話者・台詞・フキダシを直し、行を足し・消し・並べ替えて「原稿に反映」できる（元に戻すで一度に戻る）
- [ ] 「台本を流し込む…」に「# 2」「太郎「…」」「花子：…」「（…）」「ナレ：…」の台本を貼ると、ページのコマに読み順で台詞が入る。足りないページは足される
- [ ] 「入稿前の点検」（F9）で、仕上がり線の外の文字・基本枠の外・小さすぎる文字・重なったフキダシ・解像度の低い画像・紙の外の絵・向かい合わない見開き・空のページが一覧に出て、クリックでその場所が赤枠で示される

## 書き出し

- [ ] 「書き出し…」（Ctrl+E）で形式を選べ、形式ごとに必要な設定だけが出る
- [ ] 書き出した後に「フォルダを開く」で出力先が開く
- [ ] 承認箱の書き出しの依頼からは「正式な書き出し」になり、点検で止まる理由が読める

## 承認箱

- [ ] 依頼を選ぶと、編集画面もそのページに移り、プレビューが出る（ネームは読み順付き、作画は校正、設定画は候補、書き出しは点検の結果）
- [ ] 「大きく見る」（プレビューのダブルクリック）で拡大でき、← → でページを移れる。設定画の候補は並べて比べられる
- [ ] 相談には「返事を送る」で返事ができる
- [ ] 承認するとすぐに一覧から消え、エージェントの `next` から待ちが消える
- [ ] 差し戻しは理由が空だと止まり、書いた理由がエージェントの作業（`revise_page` / `fix_panel` / `make_sheet` / 相談への返事）に出る
- [ ] 設定画は候補を選ばないと承認できない。承認すると顔が切り出されてライブラリに出る
- [ ] 一括で承認するボタンが無い

## 画面2の流れ（指示 → 候補 → 採用 / 修正 → 履歴）

- [ ] ページ上でコマをクリックすると「コマ」タブにそのコマが出る
- [ ] 表示を「採用中（印刷）」「採用中（校正）」「比較」「元画像」に切り替えられる
- [ ] 候補を選ぶと来歴（ツール、モデル、実際のプロンプト、依頼、親、評価）が出る
- [ ] 指示を送るとコマに残り、エージェントの `next` に `fix_panel` が出る
- [ ] エージェントが直した候補が取り込まれると、候補の一覧に増え、親（前の候補）が分かる
- [ ] 別の候補を採用すると、印刷の表示がすぐ変わる
- [ ] 「領域を描く」でドラッグした範囲が赤（顔）・青（人物など）の枠で出て、エージェントが消せない

## 並行作業

- [ ] 編集中にエージェントが保存しても、自分の変更もエージェントの変更も消えない
- [ ] エージェントが作り直したページで自分の操作が入らなかったとき、その旨の知らせが出る
- [ ] Ctrl+Z で直前の自分の変更だけが戻る（エージェントの変更は戻らない）
