# 用語集（画面の文言）

画面に出す言葉はこの表に合わせる。左が使う言葉、右が使わない言葉。

| 使う | 使わない・使い分け |
|---|---|
| コマ | 漫画のコマの意味で「パネル」を使わない。画面の区画（ドック）は「パネル」 |
| コマの詳細 | 「コマ パネル」（コマか画面のパネルか紛らわしい） |
| フキダシ | 吹き出し |
| 台詞 | セリフ |
| ネーム・下描き・ペン入れ・仕上げ | 下書き |
| トーン | スクリーントーン |
| 見開き | — |
| 原稿 | 1 冊の本（ファイル）。作品名は「作品名」 |
| 書き出し | エクスポート |
| 承認 | 人が決めることを「確認」「確認待ち」と言わない（「承認待ち」） |
| 元に戻す・やり直す | 取り消し（履歴の「戻した操作」） |
| 消す | 削除（ボタン・メニューは「消す」に揃える） |
| AI | エージェント（画面では「AI」。説明で必要なときだけ「AI（エージェント）」） |
| 設定画 | キャラクター設定 |
| やめる | キャンセル（自前のダイアログのボタン。Qt の確認ダイアログは Qt の日本語訳の「キャンセル」のまま） |
| はい・いいえ | Yes・No |
