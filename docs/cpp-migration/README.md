# Genko Studio C++移行・改善計画

作成日: 2026-10-01 / 版: 1.0 / **計画・仕様の納品版。本体実装は未着手。**

## 決めたこと

- C++20＋Qt 6へ移行する。比較用の別実装や捨てる試作は作らない。
- GUIだけでなく、描画・編集・保存・出力・CLI・HTTP・MCPまでC++の本体とする。
- 既存機能を保持しながら、確認済みの保存保護、速度、導入、紙質、ルビ、PSD文字、表示・案内、AI接続を改善する。
- 旧Python版と原本は保持する。新しい原稿は別フォルダのv4形式にし、移行を理由にデータを失わない。
- 完成判定は性能の絶対基準、実ファイル、実機、実アプリの文字再編集、利用者の制作課題で行う。C++化すれば自動で合格するとはしない。
