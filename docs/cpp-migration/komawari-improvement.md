## 現在ある自由度

C++統合候補には斜めのドラッグ分割、コマ間の移動、角のドラッグによる輪郭変形、矩形を描いて追加するGUIがある。縦横の均等分割だけではない。

2026-10-05に現在のRelease実行物で次を実行し、4つの機能slotとinit/cleanupがPASS（Qt Totals 6PASS/0FAIL/0SKIP、exit0）した。
- `altKeepsTheAngle`: 斜め角度を維持した分割。
- `aGutterDraggedMoves`: コマ間のドラッグで寸法を変更。
- `aChosenPanelsCornerReshapesIt`: 角を動かして多角形の輪郭に変形。
- `aRectangleDrawnIsAPanel`: 任意の場所・大きさの矩形コマを追加。

証跡: `build/komawari-inspection/current-gui.log`。Qt offscreenへの入力注入による既存GUIの動作検査であり、手作業での使いやすさや全形状の受入ではない。

## 不足と追加対象

- 参考サイトは自由描画エディタというより、斜め・大ゴマ・断ち切り・コマ内分割等を調整して多数の候補を生成し、選んだ構造を変奏するツールである。この候補生成・変奏GUIは現在のC++版にはない。
- 現在の `app/templates.cpp` は自由配置したコマの `axis == "free"` を再適用すると「描いたコマのテンプレートは、この版ではまだ割れません」と拒否する。分割型のテンプレートと同じ自由度では再利用できない。この制限を解消する。

追加する制作導線:
1. **候補を生成して一覧から選ぶ。** 斜めの度合い、大ゴマ率、断ち切り、コマ内分割、段数、原稿の縦横比を調整する。会話・標準・アクション・見せゴマ等の用途から始められる。seedと設定を保持し、同じ入力から再現する。
2. **気に入った1枚をベースに別案を作る。** 小さな変奏は配置の骨格を維持して比率・角度を揺らす。大きな変奏による段数・列数の変化は明示してプレビューする。ベースへ戻れる。
3. **採用後も通常のコマとして手編集する。** コマ枠・輪郭・読み順・クリップを既存の本体モデルへ渡す。PNGの下敷きだけで終わらせず、角・境界・コマ間を編集可能にする。斜め・自由配置・曲線等の既存制作機能を均等矩形へ制限しない。
4. **自由配置した自作コマ割りを保存・再利用する。** 再適用後も輪郭、間隔、枠線、断ち切り、読み順を維持する。

## 安全性・受入

- 候補生成・閲覧・変奏だけでは原稿を変えない。既存の絵・台詞・承認・履歴を黙って削除しない。変更範囲を採用前に示し、採用は既存権限・保存モデルの原子的な1操作群とし、Undo/Redoできる。
- 不正な輪郭・交差・非有限値・過大なコマ数を既存の上限で拒否し、元原稿を保持する。枠外の絵は実コマのクリップで扱う。
- 固定seedの候補再現、低変奏時の骨格保持、採用後の斜め/角/余白編集、読み順、マスク、自由テンプレート再適用、Undo/Redo、保存再起動、PNG/PDF出力を実本体で検証する。要求・画面の記述だけを完成扱いしない。
- 担当工程はM3、総合受入はM7。Windows開発保留・配布前必須はVALIDATION.md §0に従う。
- 公式Claude Codeは週上限のため停止中。追加課金・モデル/プロバイダー切替で実装を進めない。現時点の成果は既存機能の確認と本要求記録のみ。
