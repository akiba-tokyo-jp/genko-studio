# PSD の手動確認（M6-6）

Genko の PSD は psd-tools で読み戻す試験を CI で行っている。ペイントソフトで開けるかは、ここの手順で人間が確かめる。
どちらかで開けない・レイヤーが壊れる場合は、PSD を書き出し形式から外す（設計 M6-6）。結果は `docs/eval/` に日付で残す。

## 用意

```bash
genko export PROJ out_psd --format psd --dpi 350     # ページごとに 1 ファイル
```

確認に使うページには、配置した絵・トーン・効果線・台詞（縦書き、ルビ付きを 1 つ）・ノンブルがあること。

## CLIP STUDIO PAINT

- [ ] ファイルが開ける（警告が出たら文面を記録）
- [ ] キャンバスの大きさと解像度が、書き出した dpi と判型どおり（B4 の商業原稿 257 × 364 mm なら 350 dpi で 3541 × 5016）
- [ ] レイヤー数が期待どおり（紙 1 + 絵の数 + トーン + 効果 + コマ枠 + 台詞の数 + ノンブル）
- [ ] レイヤー名が日本語のまま読める（「紙」「絵 …」「コマ枠」「台詞 …」「ノンブル」）
- [ ] 絵のレイヤーがコマの位置にあり、グレースケールで見える
- [ ] 台詞のレイヤーだけを非表示にすると文字とフキダシが消える
- [ ] 保存し直して開き直せる

## Photoshop

- [ ] ファイルが開ける
- [ ] 画像解像度が書き出した dpi
- [ ] レイヤー数とレイヤー名（日本語）が期待どおり
- [ ] 合成（全レイヤー表示）が Genko の印刷用 PNG と同じに見える（絵は網点ではなくグレー）
