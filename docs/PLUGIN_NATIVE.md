# ネイティブのフィルタープラグイン（plugin.json、プロトコル 1）

C++ 版 Genko だけの拡張です（SPEC.md COMP-04）。Python 版の `NAME / PARAMS / run(image)` のプラグイン（`<設定フォルダー>/plugins/*.py`）はそのまま使えます。ここに書くのは、Python なしで動く **プログラム** をフィルターにする形式です。ペイントのレイヤー（と補正レイヤー）に、組込みのフィルターと同じように `plugin:<キー>` でかかります。

## 置き方

```
<設定フォルダー>/plugins/<キー>/plugin.json
<設定フォルダー>/plugins/<キー>/<プログラム>        （plugin.json の executable）
```

- `<キー>` はフォルダーの名前です（`_` か `.` で始まる名前は一覧に出しません）。同じ名前の `<キー>.py` があるときは、Python のプラグインのほうを使い、このフォルダーは使えないものとして一覧に出します。
- 設定フォルダーは Genko の設定の場所です（`GENKO_CONFIG_DIR` で変えられます）。「レイヤー → プラグインの設定」の「フォルダーを開く」で開きます。

## plugin.json

```json
{
  "protocol": 1,
  "name": "セピア（ネイティブ）",
  "executable": "sepia",
  "args": ["--fast"],
  "params": {"amount": {"label": "強さ", "min": 0, "max": 1, "default": 0.8}}
}
```

| 鍵 | 要否 | 意味 |
|---|---|---|
| `protocol` | 必須 | 整数の `1`（このページの形式）。ほかの値の plugin.json は使いません |
| `name` | 必須 | フィルターの一覧に出す名前（空でない文字） |
| `executable` | 必須 | 動かすプログラム。プラグインのフォルダーの中の相対パス（`..`・絶対パス・ドライブ名は不可、フォルダーの外を指すリンクも不可）。Windows では `sepia.exe` のように拡張子まで書きます |
| `args` | 任意 | プログラムに渡す引数（文字のリスト）。そのまま渡し、シェルは通しません |
| `params` | 任意 | フィルターの画面で聞く設定。Python のプラグインの `PARAMS` と同じ形（`label`・`min`・`max`・`default`） |

plugin.json は 64 KB まで、プログラムは 256 MB までです。一覧を出すとき・名前や設定を見せるときには、plugin.json とプログラムのバイトを読むだけで、何も動かしません。

## 動かすまで

- プラグインは最初は使いません。「プラグインの設定」で「プラグインを使う」をオンにし、一覧でそのプラグインにチェックを付け、確かめの問いに「はい」と答えたものだけが動きます。
- 選んだときの plugin.json とプログラムのバイト（sha256）を覚えます。どちらかが変わったら動かさず、選び直してもらいます（動かす直前にも確かめます）。
- 別のプロセスなので、プラグインが落ちても原稿は壊れません。ただし **安全な隔離（サンドボックス）ではありません**。プログラムは、このコンピューターでそのプログラムにできることを何でもできます。

## 1 回の呼び出し（プロトコル 1）

Genko はフィルターをかけるたびにプログラムを 1 回起動します（`executable` と `args`、シェルなし）。

- 作業フォルダー: その呼び出しのための空の一時フォルダー。
- 環境変数: `PATH`・`HOME`・`USERPROFILE`・`APPDATA`・`LOCALAPPDATA`・`LANG`・`LC_ALL`・`LC_CTYPE`・`SYSTEMROOT`・`TEMP`・`TMP`・`TMPDIR`（あるものだけ）と、`GENKO_PLUGIN_PROTOCOL=1`、`GENKO_PLUGIN_HOME=<プラグインのフォルダー>`。ほかの変数（パスワードなど）は渡しません。
- 標準入力: 1 行の JSON と改行、続けて絵の画素（RGBA、1 画素 4 バイト、左上から行ごと、`width × height × 4` バイト）。

```
{"protocol": 1, "width": 100, "height": 140, "params": {"amount": 0.5}}
```

- 標準出力: 1 行の JSON と改行、続けて同じ大きさの RGBA の画素。

```
{"ok": true, "width": 100, "height": 140}
```

  断るときは `{"ok": false, "error": "理由"}` の 1 行だけ（Genko は「プラグイン「<キー>」の処理が失敗しました」と知らせます）。
- 標準エラーは読み捨てます（途中で止まったとき、最後の部分を理由として添えます）。終了コードは見ません。
- 渡すのはフィルターをかける絵（そのレイヤーの絵。補正レイヤーでは、その下に描かれたページの絵）と設定だけです。原稿のファイルは渡しません。

## Genko が止めるとき

| こと | 知らせ（日本語） |
|---|---|
| plugin.json が JSON でない・`protocol` が 1 でない・`name` がない・`executable` がフォルダーの外・プログラムがない など | 「プラグイン「…」の plugin.json が使えません（…）」（一覧では選べないものとして出す） |
| プログラムを起動できない（実行できるファイルでない など） | 「プラグイン「…」のプログラムを起動できませんでした…」 |
| 答える前に終わった（落ちた） | 「プラグイン「…」が途中で止まりました…」 |
| 120 秒で終わらない（800 万画素ごとに 120 秒） | 「プラグイン「…」が N 秒で終わらなかったため止めました」 |
| 絵より多くのデータを書いた（画素のバイト数＋64 KB を超えた） | 「プラグイン「…」が絵より多くのデータを返したため止めました」 |
| 違う大きさの絵を返した | 「プラグイン「…」が絵を返しませんでした」 |

起動できない・落ちた・終わらない・あふれたときは、補正レイヤーなら画面ではそのことを知らせて省き、書き出しでは止めます。プラグインが断ったとき・違う大きさの絵を返したときは、Python のプラグインが失敗したときと同じく、その補正レイヤーは何もしません（フィルターの操作は失敗として知らせます）。
