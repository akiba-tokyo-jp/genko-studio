# Drawing-shell Implementation Plan

> **For Hermes:** Execute this plan in this session, one task at a time. `delegate_task` only for code review.

**Goal:** 洗い出した「人の使用感」と、コマンドバスで足せる描画シェルを入れる。CSP EX 同等にはしない。

**Architecture:** GUI は引き続き `apply_ops` のクライアント。ブラシ状態は Episode に置き、ストロークは既存の `add_stroke` が読む。見開きは `set_spread` 済みの2頁を1キャンバスとして座標を振り分ける。縦組み・ゲート・NAME非出荷は触らない。

**Tech Stack:** Python 3.11, PySide6, Pillow, pytest. イワタ同梱なし。OT/CRDT なし。inspect compact に線座標を載せない。

---

## 置かない（この計画でも入れない）

- イワタ同梱、CSP プラグイン、クラウド OT/CRDT
- 印刷機プレート、油彩物理、ボーンマーケット3D、フルアニメ
- 市販スクリーントーン画像
- compact `inspect` へのストローク座標

## 置く（P8）

- `set_brush`（rgb / width_mm / stabilize / taper / curve）
- 筆圧カーブ `gpen|linear`（タブレット圧を Gペン寄りに）
- 見開きキャンバス：x が頁幅を超えた線は相手頁へ
- GUI：ツールバー（B/E、色、サイズ）、レイヤー合成コンボ、サブビュー、ショートカット
- PSD：タイトル付きユーザーレイヤーは現状どおり名前を書く
